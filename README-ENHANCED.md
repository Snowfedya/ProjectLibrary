# 📚 Enhanced Library Management System

Улучшенная версия системы управления библиотекой с мониторингом, восстановлением пароля и тестовыми данными.

## 🚀 Новые возможности

### ✨ Основные улучшения
- **📊 Мониторинг Grafana** - Красивые дашборды с метриками JVM и HTTP
- **🔍 Prometheus метрики** - Подробная телеметрия приложения  
- **📧 Email система** - Восстановление пароля через MailDev
- **🔐 Восстановление пароля** - JWT-токены для безопасного сброса
- **🧪 Генерация тестовых данных** - Автоматическое создание пользователей и книг
- **🏥 Health checks** - Мониторинг состояния системы

### 🎯 Выполненные требования
- [x] **Продуманная Grafana**: Метрики JVM, HTTP запросы, производительность
- [x] **Нагрузочные данные**: Автоматическая генерация пользователей и книг
- [x] **Восстановление пароля**: JWT токены + Email уведомления
- [x] **Email уведомления**: Интеграция с MailDev для тестирования
- [x] **Удобный запуск**: Один скрипт запускает всю систему
- [x] **Мониторинг**: Prometheus + Grafana для наблюдаемости

## 📋 Требования

- **Java 21+** 
- **Maven 3.8+**
- **Docker & Docker Compose**
- **2GB+ RAM** для всех сервисов

## 🎪 Демонстрация функций

### 1. Основная система (5 мин)
1. Откройте http://localhost:8080
2. Войдите как администратор
3. Просмотрите каталог книг и пользователей
4. Протестируйте основные операции

### 2. Восстановление пароля (3 мин) 
1. Перейдите на http://localhost:8080/forgot-password
2. Введите email любого пользователя
3. Проверьте письмо в MailDev: http://localhost:1080
4. Перейдите по ссылке и смените пароль
5. Войдите с новым паролем

### 3. Мониторинг Grafana (3 мин)
1. Откройте Grafana: http://localhost:3000
2. Войдите: admin / admin123
3. Просмотрите дашборд "Library Management System - Basic Metrics"
4. Обратите внимание на метрики:
   - HTTP Request Rate
   - JVM Memory Usage
5. Откройте несколько страниц приложения и посмотрите изменения

### 4. Prometheus метрики (2 мин)
1. Откройте Prometheus: http://localhost:9090
2. В строке поиска введите: `http_server_requests_seconds_count`
3. Нажмите Execute и изучите метрики
4. Попробуйте другие метрики: `jvm_memory_used_bytes`

## 📊 Доступные метрики

### HTTP метрики
- `http_server_requests_seconds_count` - Количество HTTP запросов
- `http_server_requests_seconds_sum` - Общее время обработки
- `http_server_requests_seconds_max` - Максимальное время ответа

### JVM метрики  
- `jvm_memory_used_bytes` - Использование памяти
- `jvm_memory_max_bytes` - Максимальная память
- `jvm_threads_live_threads` - Количество потоков

### Health метрики
- `system_cpu_usage` - Использование CPU
- `process_uptime_seconds` - Время работы приложения
