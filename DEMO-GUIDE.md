# 🎯 Руководство по демонстрации

## 🚀 Быстрый запуск (2 минуты)

```bash
# 1. Запуск системы
./start-enhanced.sh

# 2. Дождитесь сообщения "Система запущена!"
```

## 📋 Сценарий демонстрации (15 минут)

### Этап 1: Основная функциональность (5 мин)

**1.1 Вход в систему**
- Откройте http://localhost:8080
- Войдите: `admin@library.com` / `admin123`
- Покажите главную страницу каталога

**1.2 Управление**
- Продемонстрируйте просмотр книг и пользователей
- Покажите основные операции системы

### Этап 2: Восстановление пароля (4 мин)

**2.1 Запрос сброса**
- Откройте http://localhost:8080/forgot-password
- Введите email: `student@university.edu`
- Нажмите "Отправить"

**2.2 Проверка email**
- Откройте MailDev: http://localhost:1080
- Покажите полученное письмо
- Перейдите по ссылке из письма

**2.3 Смена пароля**
- Установите новый пароль: `newpassword123`
- Войдите с новыми данными

### Этап 3: Мониторинг Grafana (4 мин)

**3.1 Grafana Dashboard**
- Откройте http://localhost:3000
- Войдите: `admin` / `admin123`
- Покажите дашборд "Library Management System - Basic Metrics"

**3.2 Метрики в реальном времени**
- Откройте несколько вкладок с приложением
- Обновите несколько страниц
- Вернитесь в Grafana - покажите изменения в метриках:
  - HTTP Request Rate
  - JVM Memory Usage

### Этап 4: Prometheus метрики (2 мин)

**4.1 Raw метрики**
- Откройте http://localhost:9090
- В поиске введите: `http_server_requests_seconds_count`
- Покажите сырые данные метрик
- Попробуйте: `jvm_memory_used_bytes`

## 🔧 Техническая архитектура

**Spring Boot приложение** с:
- Spring Security для аутентификации
- Spring Data JPA для работы с БД
- Spring Mail для email
- Spring Boot Actuator для метрик

**Инфраструктура**:
- PostgreSQL - основная база данных
- Prometheus - сбор метрик
- Grafana - визуализация метрик  
- MailDev - тестирование email

**Мониторинг**:
- HTTP метрики (запросы, время ответа)
- JVM метрики (память, потоки)
- Health checks
- Custom метрики приложения

## ⚠️ Возможные проблемы

**Порты заняты**: Убедитесь что порты 8080, 3000, 9090, 1080, 5432 свободны

**Медленный запуск**: Docker может долго скачивать образы при первом запуске

**Приложение не стартует**: Проверьте логи в `library-app.log`
